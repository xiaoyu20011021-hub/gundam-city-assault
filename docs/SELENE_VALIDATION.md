# SELENE 可选地图验证

日期：2026-10-20。

## 接入范围

作战准备页新增地图选择，原静海地图保留。SELENE 场景从 `C:/Users/BobbyYuri/Desktop/哆啦A梦/src/world/` 复制后适配到 `src/content/maps/selene/`；原目录未修改。地球图片位于 `public/assets/selene/earth-atmosphere.jpg`，来源沿用原场景记录的 Three.js examples 地球纹理。

城区缩放为 1/3。玩家作战范围 X/Z 各 ±140，中央街道出生点为 (0,60)，菜单和整备库使用独立的城南展示位置。外围高架环城、港口、质量投射器、陨坑与交通构成远景。

建筑碰撞按基座、分体塔身、屋顶层级和大型护甲支撑分段生成。`RectCollider.minY` 表示悬空实体底部；旧图未设置时仍从地面起算。弹道、机体移动、上升撞底、屋顶支撑和浮游炮都使用该高度区间。平地寻路只考虑会阻挡地面机体的部分；AI 飞行避障显式使用占地投影估计越楼高度。细灯带、天线与细管线为装饰；斜切和八角轮廓采用矩形近似，本次未实现任意斜坡、桥下分层道路或全城漫游。

## 自动验证

执行 `npm test -- --reporter=dot`、`npm run build`、`git diff --check`。

最终结果：32 个测试文件、176 项测试全部通过；TypeScript 检查与 Vite 生产构建通过；差异检查退出码为 0。

新增测试覆盖：

- 两张地图注册与合法选择；出生点净空、实际寻路网格连通；移动、弹道和屋顶落地。
- 异步切图成功替换、失败保留旧场景、重试、返回、连续选择只接受最后一次结果、销毁后拒绝迟到结果。
- 界面保留机体／任务／推进／AI 组合，返回原图时恢复渲染环境。
- 分体双塔低屋顶与高处缺口；对可见 `InstancedMesh` 进行垂直 Raycaster 取交点，确认机体落点和真实可见屋顶一致。
- 两种 AI 的飞行避障，以及上升撞底、悬空实体下方通行、射击和浮游炮移动。
- 场景、共享几何、材质、纹理和实例缓冲幂等释放；迟到纹理在地图销毁后立即释放。
- 整备库相机不处于任意实例化实体方块内部。完整建城的综合测试使用 20 秒上限，以容纳全量并行测试的 CPU 竞争。

代码独立审阅发现并已修复：双塔短侧悬空落地、`minY` 对飞行 AI 占地查询的影响、大型侧支撑遗漏。最终复查未发现明确 P1/P2。浏览器另发现整备库镜头落入环轨站房屋顶，已调整城南展示镜头并补充实例几何对照测试。
