## 浏览器观察

使用本任务独立的 Chrome profile，经 browser-harness 控制。最终成功的检查使用 GPU，1440×1000 视口、低画质；没有使用用户的 Chrome profile。游戏服务通过 `node scripts/start-game.mjs --no-open` 启动，本次地址为 `http://127.0.0.1:5174/`，HTTP 200 已核对。

- `tests/nu-preview.html`：实际渲染检查正面、侧面、背面；大头短肢、四片天线、长盾、步枪与左背单侧六炮清楚可见。
- 正式菜单可选择 RX-93，整备库显示五台机体，卡片与展示顺序一致；牛高达选中后出击按钮可用。
- 正式夏亚单挑、增强 AI：点击出击后真实 pointer lock 成功，玩家类型为 `nu-gundam`。
- 约 0.45 秒时四枚在出击；约 0.88 秒时六枚均离架；约 1.7 秒时六枚均攻击，夏亚耐久从 300 下降到 228。
- 约 3.33 秒时一枚炮 HP 从 48 下降到 36，其余仍为 48，证明实际弹丸通道可以单独伤害炮。
- 站立不操作的该轮最终在 8.28 秒失败；母机死亡时炮实体同步清空，任务击杀仍为 0。这不是胜利或完整平衡性证明。
- 点击整场重开后六枚恢复 48；真实 T 键事件切换到第一人称，手持专属步枪正常，世界空间炮继续运行。
- 释放 pointer lock 暂停，间隔读取的模拟时间和炮状态完全一致；继续后真实 F、2 键事件分别起飞和切换军刀，约 3.6 高度悬停、推进能量约 88，六枚炮继续攻击。
- 该 GPU 低画质样例稳定阶段 HUD/诊断约 60 FPS；开始出击阶段出现 34/49 的瞬时读数。三人称战斗一次读数约 158 次绘制、172156 三角形；第一人称暂停一次约 43 次绘制、132460 三角形。数值受镜头裁剪、效果和当前炮状态影响，不是硬件横评，也不是加入前后严格性能对照。
