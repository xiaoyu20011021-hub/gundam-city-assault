# 已确认的首版设计

- HTML 3D、Three.js + TypeScript + Vite，本地单人，电脑键鼠。
- 精致卡通 SD 比例；高达可驾驶，绿色扎古和夏亚红色带角扎古为 AI 敌人。
- 高达步枪/军刀，扎古机枪/热能斧，三波城市作战。
- 自行制作可编辑的分件机体与武器；优先使用 Kenney CC0 楼宇、道路、科幻及撞击音效。
- 第三人称自由瞄准、推进、跳跃；碰撞与遮挡、连续弹丸检测、近战单次命中、寻路。
- 具备加载、开始、暂停、结算、重开、画质与静音设置；失焦/鼠标解锁自动暂停。
- 核心、玩法、内容与 UI 分离，地图/机体/武器通过定义与注册表扩展。

本文件记录用户确认的实现范围。实际代码布局及扩展方式见 ARCHITECTURE.md。
