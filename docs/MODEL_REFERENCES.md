# 机体造型参考

本次依据万代官方商品实拍重新构建程序化模型。为适配现有骨架和战斗镜头，统一头身比例与关节位置，并保留低面数装甲切面。

| 机体 | 官方参考 | 本项目采用的造型 |
| --- | --- | --- |
| RX-78-2 | [万代中国 SDEX STANDARD 001](https://bandaihobbysite.cn/index/index/detail/id/1596) | 白色 V 字天线、黄色双眼、红额头与下巴、横向面罩槽、蓝胸黄色格栅、腰部黄块、红白联邦盾 |
| MS-06F | [万代 SDCS 扎古 II 商品图](https://global.bandai-hobby.net/en-us/item/01_3295/) | 组合商品中的普通扎古形态：圆顶头盔、黑色独眼带、粉红单眼、分节动力管、梯形口罩、黑色胸心、左刺肩与右肩盾 |
| MS-06S | 与 MS-06F 共用扎古结构 | 夏亚红色涂装与指挥官角，同步修正独眼遮挡、动力管与装甲轮廓 |
| RGM-79 | [万代 FW GUNDAM CONVERGE 3 中的吉姆](https://www.bandai.co.jp/candy/gundam/converge/03/) | 青绿色一体面罩、额头传感器、红胸与肩甲、小型黄色进气口、白色腰甲、单军刀背包、短管喷枪和联邦盾 |

吉姆参考为官方 CONVERGE 的变形比例商品，再适配为本项目的可动 SD 比例。官方商品图仅用于观察；游戏模型由几何代码构建。

`federation-heads.ts` 构建高达／吉姆头部，`gundam.ts` 构建联邦共享结构，`gm.ts` 提供独立定义；`zaku.ts` 构建两种扎古。`geometry.ts` 管理切面装甲、沿曲线排列的动力管与资源释放。
