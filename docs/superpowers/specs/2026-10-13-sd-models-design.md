# SD 机体造型与吉姆

目标：依据万代官方 SD 商品参考，优化 RX-78-2、MS-06F、MS-06S，增加可展示、可驾驶的 RGM-79 吉姆。

选择继续使用程序化分件模型：相比只调整配色，这能修正轮廓；相比引入外部网格，能保留现有骨架、资源释放和离线运行。联邦机体共享四肢、背包与盾牌构造，头部和胸部按型号区分。

RX-78-2：白色 V 字天线、黄色双眼、红色额头与下巴、横向面罩槽，扩大头部并以切面头盔取代方盒，调整胸口进气口、腰甲黄色块和靴子轮廓。
扎古：球面头盔与真正外露的黑色独眼带、粉色独眼、沿路径均匀排列的动力管节、圆鼓小腿；保留左刺肩、右肩盾及夏亚指挥官角。
吉姆：浅灰绿四肢与头盔、红胸、绿色一体面罩、单根背包军刀、光束喷枪及联邦盾牌。复用光束军刀动画，喷枪独立武器定义。

整备库扩为四台，吉姆可选择出击；菜单、HUD 和重开保持所选机体一致。敌人波次沿用原配置。

验收：所有机体脚底 y=0，枪口朝 -Z；吉姆武器切换、资源释放、飞行瞄准通过测试；实际浏览器核对四台展示、吉姆出击、旋转与军刀展示；npm test 与 npm run build 通过。

参考链接与采用细节记录于 docs/MODEL_REFERENCES.md。官方图片仅供观察，模型为本项目重新构建。
