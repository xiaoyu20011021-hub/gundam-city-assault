# 夏亚扎古一对一单挑模式

## 目标

在现有月面都市作战准备页增加“夏亚单挑”模式。玩家驾驶已支持的高达或吉姆，与唯一一台夏亚专用扎古作战；现有三波战役继续保持原样。

## 方案

在出击菜单增加独立的“任务类型”选择，提供标准战役与夏亚单挑。单挑沿用月面都市地图、玩家机体选择、推进规则、敌方 AI 难度和现有战斗生命周期，不另建地图或平行战斗系统。

战斗开始时，Mission 接收本局波次配置：标准战役使用地图原有三波；单挑使用仅含一台 `char-zaku` 的单波配置。现有生成、移动、碰撞、射击、受击、胜负、暂停、重开和结算流程继续处理这场战斗。

## 界面与状态

- 新增 `BattleMode`，与现有推进能量设置 `SortieMode` 分离。
- 菜单可切换“标准战役 / 夏亚单挑”；机体、推进和 AI 选择彼此独立。
- 选择在当前页面与本局生命周期内保留，重开和从整备库出击沿用当前模式；刷新行为与现有非持久化出击选择一致。
- HUD 按模式显示任务名称、单挑目标或战役波次，以及正确的敌机总数。
- 结算显示本局击破数和模式对应的分母；单挑与战役分别保存本地最佳成绩，并保留现有战役成绩键。

## 不在范围内

- 不新增专用竞技场、第二名玩家、可选对手或新的战斗规则。
- 不改变夏亚扎古属性、AI 控制器、武器数值或标准战役波次。

## 涉及位置

- `src/gameplay/mission.ts`：支持一局传入本次任务使用的波次配置。
- `src/gameplay/game.ts`：管理战役/单挑选择，配置单挑敌机和模式独立成绩。
- `src/ui/ui.ts`：增加任务选择并动态更新菜单、HUD 与结算计数。
- `README.md`：说明单挑入口、对手和可组合设置。

## 验收标准

- 选择单挑后，月面都市中只生成一台夏亚专用扎古。
- 击败该敌机后获胜；玩家先被击败则失败；单挑不进入战役后续波次。
- 重开和整备库出击沿用所选任务类型。
- 单挑 HUD 和结算体现一个敌机目标；单挑成绩不覆盖战役成绩。
- 标准战役仍依次生成原有 4、6、5 台敌机，既有 AI、推进、战斗与设置行为不变。

## 验证

实现后运行 `npm run build` 检查类型与打包。依照本次指令，仅做构建验证，不新增或运行测试。
