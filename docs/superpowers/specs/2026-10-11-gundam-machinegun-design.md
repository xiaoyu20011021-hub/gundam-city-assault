# 高达第三武器：机枪设计

## 目标

为玩家驾驶的 RX-78-2 增加可直接选择的第三把武器机枪；继续保留光束步枪和光束军刀，敌方机体武器不变。

## 已确认的操作

- `1` 选择光束步枪，`2` 选择光束军刀，`3` 选择机枪。
- 按住鼠标左键时，机枪按射速自动连射；松开即停止。
- 机枪不使用弹匣，改用与光束步枪独立的热量和过热状态。过热后停止射击，冷却后可继续使用。
- 机枪只作为玩家高达的第三把武器；扎古和夏亚专用扎古保持现有配置与 AI 行为。

## 实现设计

沿用现有弹丸、瞄准点、碰撞和音效流程。武器定义新增独立的高达机枪 ID，采用低于光束步枪的单发伤害、更短射击间隔、较短射程和独立热量参数。初始调校建议为 14 点伤害、0.11 秒间隔、145 单位射程、150 单位弹速、每发增加 7 点热量、冷却速度每秒 40 点；这些数值沿用现有热量机制，可在实际游玩后再调整。

武器模型在高达右手挂点增加独立机枪组和枪口挂点。机体武器槽增加 `machinegun`，切换武器时只显示当前武器，并使用对应枪口发射。玩家为各远程武器保存独立 `WeaponState`，切换武器不会重置另一把枪的热量。敌机仍使用其定义中的原远程武器和 AI 弹匣逻辑。

HUD 增加 `3 机枪` 选择指示；选择机枪时复用热量条显示其热量、过热及冷却状态。菜单、暂停控制说明、整备库介绍和 README 同步显示三把武器与 `1 / 2 / 3` 切换方式。

## 验收条件

- 1、2、3 可分别选择步枪、军刀、机枪，模型与 HUD 选择状态一致。
- 机枪按住左键连射、松开停止；过热后不再发射，冷却后恢复。
- 切换到机枪不会继承或清除步枪热量，切回步枪行为保持不变。
- 机枪弹丸仍被建筑阻挡并能击中敌机；敌方扎古及夏亚扎古武器配置、射击行为保持不变。
- 现有飞行与屋顶交战改动继续保留。
