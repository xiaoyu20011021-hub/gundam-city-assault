# Flight Implementation Plan

**Goal:** 实现已确认的 F 切换辅助悬停飞行和敌机空战，启动本地游戏供用户试玩。

**Architecture:** 玩家输入和 AI 都输出 MovementIntent，通过共享移动控制器更新 Actor。独立 spatial 模块处理立体墙体、屋顶支撑、位移与机体分离；战斗、相机与 HUD 消费最终状态。

**Tech Stack:** TypeScript, Three.js, Vitest, Vite。

## 1. 测试与物理
- [x] 新增 tests/flight.test.ts：三机体起飞、视线方向 W、松键悬停、合成速度、耗尽、再起飞阈值、帧率一致性、屋顶和墙体、顶高。
- [x] 运行 `npm.cmd test -- tests/flight.test.ts` 确认功能缺失导致失败。
- [x] src/gameplay/spatial.ts 提供 supportHeight(position, radius, walls)、moveBody(position, delta, radius, height, walls, bounds)；小步逐轴碰撞，下降夹到屋顶/地面。
- [x] 扩展 Actor 飞行状态、恢复延迟和起飞目标；movement.ts 使用三维目标速度和指数积分，统一地面/飞行/降落状态。
- [x] 运行飞行测试及已有 simulation 测试。

## 2. 战斗与 AI
