# SD GUNDAM · 城市突入

支持第一／第三人称切换的 3D SD 高达射击游戏。驾驶 RX-78-2 高达、RGM-79 吉姆、RX-93 牛高达或 MS-09 大魔，使用光束步枪／光束喷枪、追踪火箭筒、军刀以及牛高达的六枚自动浮游炮，在城市中迎战绿色扎古、夏亚专用红色扎古与 MS-09 大魔。

作战准备页的 **作战地图** 可选择两张地图：

- **月面都市 · 静海战线**：原有街区、装甲殖民建筑、战损、整备坪、月壤和陨石坑。
- **SELENE · 冯·布朗月面都市**：从本地月面都市场景移植，约三分之一比例；中央平坦街区为 280 × 280 的作战区域，保留塔群、分层环城、生态穹顶、宇宙港、机库、质量投射器、地球和运行中的交通作为整体景观。外围复杂分层区域为远景，作战边界有地面标记。

两张地图均可搭配现有三台机体、标准战役／夏亚单挑、标准／无限推进、经典／增强 AI。返回作战准备后可换图；重新出击保留当前地图。地图在本地程序化生成，重复构件使用实例化绘制，画质选择同时适用于两张地图。SELENE 的场景源码和地球纹理已经存入本项目，运行不依赖原“哆啦A梦”目录。

## 启动

Windows 双击 **start-game.cmd**。首次启动自动安装依赖并打开浏览器；此后资源从本地载入。保持启动窗口开启，按 Ctrl+C 关闭服务。

需要 Node.js **22.12 或更高版本**，推荐 Node.js 24。推荐使用开启图形加速的 Chrome 或 Edge。游戏通过本地 HTTP 服务运行，不能直接双击 index.html。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端输出的本地地址。首次依赖安装需要网络；城市、机体和音效均已保存到本项目，游戏过程不请求第三方资源。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 旋转视角 | 鼠标 |
| 第一／第三人称切换 | T |
| 射击 / 挥砍 | 鼠标左键 |
| 精确瞄准 | 鼠标右键 |
| 光束步枪 / 光束军刀 | 1 / 2 |
| 推进闪避 | Shift（按住） |
| 推进跳跃 | Space |
| 飞行 / 降落 | F |
| 飞行上升 / 下降 | Space / Ctrl |
| 朝准星三维方向飞行 | W（S 后退，A / D 侧移） |
| 空中加速 / 悬停 | Shift＋方向键 / 松开移动键 |
| 暂停 / 释放鼠标 | Esc |

每次出击默认第三人称，按 T 切换到手持武器的第一人称，再按 T 返回。长按不会反复切换；暂停后继续保留当前视角，重新出击恢复第三人称。第一人称支持三台可驾驶机体及其武器和飞行，右键缩小视场以精确瞄准，切换视角不改变弹药、热量或武器冷却。

牛高达的六枚 Fin Funnel 自动搜索附近无遮挡的敌机，优先攻击准星指向的有效目标，分散攻击后自动归队补能，不需要额外按键。每枚有独立的 48 点血量，可以被敌方枪弹和近战击毁；回收只补能，不修复损伤。击毁后本场永久损失，跨波次、暂停、视角切换及无限推进均不复活；重新开始整场出击才补齐六枚。左上角六格面板显示每枚血量、当前状态和攻击目标，母机背包同步保留真实空缺。牛高达使用 1 步枪、2 军刀，不配备 3 号机枪。

推进和跳跃消耗推进能量。飞行启动要求至少 20 点并消耗 8 点；悬停、普通飞行、空中加速分别每秒消耗 4、6、18 点。地面或楼顶停止推进 0.6 秒后，每秒恢复 24 点。能量耗尽后限速下降，可有限平移和攻击，无坠落伤害；能量足够时可以在降落途中按 F 恢复飞行。高度上限 100。

作战准备页可选择“无限推进”模式：玩家与敌机起飞、飞行、空中加速、地面冲刺和跳跃均不消耗能量；标准模式沿用上述原有规则。该选择在本次游戏会话中保留。

“敌方 AI”可独立选择，默认使用 **经典 AI（原版难度）**，保留原来的战斗方式。**增强 AI** 会按弹速预判玩家的横移与升降，并在发现危险弹道后侧移、推进或在空中改变高度躲避。普通扎古约 0.22 秒反应，夏亚约 0.12 秒；闪避有持续时间与冷却，仍受建筑、边界和能量限制。急停、变向、近距离攻击和持续压制仍能命中敌机。

AI 选择在刷新后保留，在下一次出击生效，也适用于整备库出击与重新出击；可与标准/无限推进自由组合。HUD、暂停及结算显示当前 AI，经典与增强分别保存最佳成绩，原有经典成绩保留。当前难度的源码基线另存于 `src/gameplay/ai-classic.ts`；升级前完整快照位于桌面 `高达射击-备份/ai-classic-20261015-130906.zip`（101 个文件经过 SHA-256 校验）。

“任务类型”可选三波标准战役或“夏亚单挑”。单挑沿用月面都市地图，只与一台夏亚专用扎古作战；三台可驾驶机体、推进规则和敌方 AI 均可独立选择。单挑成绩与标准战役成绩分开保存。

飞行时抬头按 W 爬升、低头按 W 俯冲，松开移动键自动刹停并保持高度。只移动鼠标可以原地瞄准。高达、普通扎古、夏亚扎古都能飞行，敌机也会起飞追击、避让建筑并落地补能。

光束步枪连射会过热，等待冷却后恢复。军刀有前摇和后摇，每次挥砍对同一敌人只命中一次；空战近战按实际高度、朝向和建筑遮挡判定。

三波为 4 台绿色扎古、4 台绿色扎古＋2 台大魔、夏亚扎古＋3 台绿色扎古＋1 台大魔。耐久归零失败，清除全部敌机获胜。最佳积分与画质/静音偏好保存在浏览器本地。

作战准备画面可选择高达、吉姆、牛高达或大魔出击，也可进入机体整备库单独查看六款机体、旋转模型并切换展示武器，进入时默认展示新增的大魔。选中可驾驶机体后可直接出击；重新出击和返回菜单保留本次所选机体。官方造型参考与实现取舍见 [机体参考](docs/MODEL_REFERENCES.md)。

## 可驾驶机体与敌人：MS-09 大魔

紫黑装甲、红边十字独眼、宽肩钟形裙甲和短粗悬浮腿组成 SD 比例的独立分件模型，装备肩扛式巨型火箭筒与背负热能军刀。移动时保持双脚平稳滑行；近身会改用热能军刀。

大魔耐久 240，火箭直击伤害 65，爆炸半径 7，范围伤害随距离衰减；建筑会阻挡火箭和爆炸伤害。敌方大魔每发火箭先进行 0.85 秒瞄准，独眼及 HUD 提示预警，初始瞄准的是前摇开始时的位置，可以通过推进或掩体躲避。火箭飞行速度 42，每 3 发装填一次，装填耗时 3.6 秒；发射间隔另受冷却与瞄准前摇约束。火箭只伤害敌对阵营。

大魔在经典和增强 AI 下均采用带瞄准前摇的地面重火力行为；火箭也可以击中或波及敌对的浮游炮。两张地图的标准战役均包含大魔，夏亚单挑保持一对一。

大魔现可从作战准备或机体整备库直接出击；`1` 火箭筒、`2` 热能军刀、`T` 切换第一／第三人称，沿用现有飞行与推进操作。玩家无需敌机的瞄准前摇。火箭在发射方向 20° 内自动捕获 100 米内可见敌人或敌对浮游炮，优先靠近准星的目标；最多追踪 1.5 秒，每秒最多转向 36°。目标死亡、进入掩体或偏离弹头方向 60° 后，火箭继续直飞且不会重新锁定。双方使用相同制导规则。爆炸带亮闪、火球、冲击环、火星与烟尘，沿用原有范围伤害与掩体阻挡规则。

## 性能与诊断

默认中画质包含阴影，低画质关闭阴影并限制像素比。HUD 展示实际帧率。添加 `?debug=1` 后，控制台可调用 `sdDiagnostics()` 读取机体、波次、镜头和渲染统计，诊断接口不改变游戏状态。

程序分件模型和几何源码保留在内容模块中，机体与武器无需外部建模软件即可修改。Kenney 城市及音效使用 CC0；完整来源与原始许可证随资源提供。
