# SD GUNDAM · 城市突入

第三人称 3D SD 高达射击游戏。驾驶 RX-78-2 高达或 RGM-79 吉姆，使用光束步枪／光束喷枪和光束军刀，在城市中迎战绿色扎古和夏亚专用红色扎古。

## 启动

Windows 双击 **start-game.cmd**。首次启动自动安装依赖并打开浏览器；此后资源从本地载入。保持启动窗口开启，按 Ctrl+C 关闭服务。

需要 Node.js **22.12 或更高版本**，推荐 Node.js 24。推荐使用开启图形加速的 Chrome 或 Edge。游戏通过本地 HTTP 服务运行，不能直接双击 index.html。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端输出的本地地址。首次依赖安装需要网络；城市、机体和音效均已保存到本项目，游戏过程不请求第三方资源。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 旋转视角 | 鼠标 |
| 射击 / 挥砍 | 鼠标左键 |
| 精确瞄准 | 鼠标右键 |
| 光束步枪 / 光束军刀 | 1 / 2 |
| 推进闪避 | Shift（按住） |
| 推进跳跃 | Space |
| 飞行 / 降落 | F |
| 飞行上升 / 下降 | Space / Ctrl |
| 朝准星三维方向飞行 | W（S 后退，A / D 侧移） |
| 空中加速 / 悬停 | Shift＋方向键 / 松开移动键 |
| 暂停 / 释放鼠标 | Esc |

推进和跳跃消耗推进能量。飞行启动要求至少 20 点并消耗 8 点；悬停、普通飞行、空中加速分别每秒消耗 4、6、18 点。地面或楼顶停止推进 0.6 秒后，每秒恢复 24 点。能量耗尽后限速下降，可有限平移和攻击，无坠落伤害；能量足够时可以在降落途中按 F 恢复飞行。高度上限 100。

作战准备页可选择“无限推进”模式：玩家与敌机起飞、飞行、空中加速、地面冲刺和跳跃均不消耗能量；标准模式沿用上述原有规则。该选择在本次游戏会话中保留。

飞行时抬头按 W 爬升、低头按 W 俯冲，松开移动键自动刹停并保持高度。只移动鼠标可以原地瞄准。高达、普通扎古、夏亚扎古都能飞行，敌机也会起飞追击、避让建筑并落地补能。

光束步枪连射会过热，等待冷却后恢复。军刀有前摇和后摇，每次挥砍对同一敌人只命中一次；空战近战按实际高度、朝向和建筑遮挡判定。

三波为 4 台绿色扎古、6 台绿色扎古、夏亚扎古＋4 台绿色扎古。耐久归零失败，清除全部敌机获胜。最佳积分与画质/静音偏好保存在浏览器本地。

作战准备画面可选择高达或吉姆出击，也可进入机体整备库查看四款机体、旋转模型并切换展示武器。选中高达或吉姆后可直接出击；重新出击和返回菜单保留本次所选机体。官方造型参考与实现取舍见 [机体参考](docs/MODEL_REFERENCES.md)。

## 性能与诊断

默认中画质包含阴影，低画质关闭阴影并限制像素比。HUD 展示实际帧率。添加 `?debug=1` 后，控制台可调用 `sdDiagnostics()` 读取机体、波次、镜头和渲染统计，诊断接口不改变游戏状态。

程序分件模型和几何源码保留在内容模块中，机体与武器无需外部建模软件即可修改。Kenney 城市及音效使用 CC0；完整来源与原始许可证随资源提供。
